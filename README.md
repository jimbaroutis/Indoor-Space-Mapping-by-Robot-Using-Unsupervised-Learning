# Indoor-Space-Mapping-by-Robots-Using-Unsupervised-Learning

We define a grid-based graph upon which a robot is programmed to navigate—traversing the grid's edges to reach target nodes—in order to perform specific tasks. The graph consists of "free" nodes, which the robot can access at any time, and "obstacle" nodes, which—along with the boundaries of the graph—are considered inaccessible. In addition to these static obstacles, there is a dynamic obstacle: a human moving freely within the space defined by the grid. Unlike the robot, which is restricted to the graph's nodes, the human can be located anywhere within the grid, not just at the node positions. The robot’s objective is to complete its movements by following the safest among the available paths, while also accounting for the presence of humans. Specifically, the robot will select a path from a root node to a target node that is, primarily, as far as possible from the nearest static obstacle and, secondarily, has the shortest length.

We assume that the workspace shared by the human and the robot is known to the robot and is monitored by a system utilizing a global radar, which provides the robot with information regarding the environment's structure. In this way, the robot learns the layout of the space and calculates the most suitable path to follow. Furthermore, the radar detects the human's state specifically, their direction of movement and speed. Consequently, before beginning its movement, the robot receives timely alerts from the monitoring system regarding any potential collision with the human, allowing it to take preemptive avoidance actions.
